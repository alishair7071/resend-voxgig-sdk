# Security Policy

## Reporting a vulnerability

Please report security issues privately to Ali Shair.

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/alishair7071/resend-voxgig-sdk/issues

## Scope

This policy applies to the generated Ali Shair SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the Resend public API, generated by
Ali Shair. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
